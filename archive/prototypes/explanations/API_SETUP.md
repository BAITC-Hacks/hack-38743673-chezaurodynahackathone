# Настройка API для второго и третьего этапов

Требуется Python 3.11+; дополнительные пакеты не нужны. Для OpenAI оба этапа могут
использовать один серверный ключ. Второй этап по умолчанию вызывает `gpt-5.4-nano`,
третий — `gpt-5.4-mini`. Выбор модели третьего этапа задаётся отдельно.

## Проверка без ключа

В терминале PowerShell из папки `Hackathon`:

```powershell
python -m unittest discover -v
python verify_profile_explanations.py
```

Демонстрация использует заглушку и показывает формат данных. Она не оценивает качество ИИ.

## Куда вставить свой ключ

Скопируйте `set_test_key.ps1.example` в `set_test_key.ps1` (если локального файла ещё нет).
В локальном файле замените `вставьте_сюда_ваш_ключ_OpenAI` своим новым ключом.
Затем выполните в том же терминале:

```powershell
. .\set_test_key.ps1
python verify_profile_explanations.py --live
```

Команда `--live` делает один запрос только для третьего этапа по трём демонстрационным
профилям из `examples/selected_profiles.json`. Расходы и доступность модели зависят
от вашего API-проекта. Для отдельной проверки второго этапа: `python verify_openai_proxy.py`.

Если PowerShell не разрешает запуск локального скрипта, задайте `AI_PROXY_API_KEY`
через настройки окружения запуска IDE или веб-сервера. Простое открытие `.ps1`
и запуск `python smartmatch.py` не загружают ключ и не запускают сайт.

## Настройки собственного прокси

| Переменная | Назначение |
| --- | --- |
| `AI_PROXY_API_KEY` | Общий ключ для двух этапов |
| `AI_PROXY_URL` | Общий полный URL Chat Completions |
| `AI_PROXY_MODEL` | Модель второго этапа |
| `EXPLANATION_PROXY_API_KEY` | Отдельный ключ третьего этапа, если нужен |
| `EXPLANATION_PROXY_URL` | Отдельный URL третьего этапа, если нужен |
| `EXPLANATION_PROXY_MODEL` | Модель третьего этапа, по умолчанию `gpt-5.4-mini` |

Если отдельные URL и ключ третьего этапа не указаны, используются общие значения.
Модель третьего этапа **не** наследуется из `AI_PROXY_MODEL`.
Прокси третьего этапа должен поддерживать Chat Completions, `max_completion_tokens`
и `response_format` типа `json_schema` (Structured Outputs).

На хостинге задайте эти переменные в настройках серверного приложения. Локальный
`set_test_key.ps1` не отправляется в репозиторий или браузер. `.env` автоматически
не загружается этим модулем. Шаблон `.ps1.example` оставляйте без действующего ключа.

## Ошибки при проверке

- Нет ключа: загрузите его в том терминале, из которого запускается Python.
- HTTP 401: проверьте ключ для указанного URL.
- HTTP 403/404: проверьте URL, имя модели и права API-проекта.
- HTTP 429: проверьте квоту и лимиты API-проекта.
- Тайм-аут или некорректный ответ: сохраните исходные карточки на сайте и покажите,
  что объяснения временно недоступны; пример обработки есть в README.
